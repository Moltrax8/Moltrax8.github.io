DailyHub.

A local-first Android productivity app for tasks, notes, and subtasks, with recurring schedules, reminders, a focus timer, and configurable home-screen widgets.

View GitHub repository ↗All projects ←
OVERVIEW

DailyHub is an Android app designed to keep everyday tasks and notes on the device. It does not require accounts or cloud synchronization.

It combines task tracking, recurrence, subtasks, standalone notes, calendar features, reminders, and a focus timer in a native Android interface.

FEATURES & APPROACH

What it includes

  • Tasks with notes, tags, deadlines, subtasks, and flexible recurrence rules.
  • Standalone notes with pinning and search.
  • Calendar, reminders, and per-task focus timer.
  • Configurable home-screen widgets with checklist actions and layout preferences.
  • Local storage; optional release-update checks via GitHub.

Keevra.

Local-first Windows desktop app for organizing service accounts in an encrypted on-device vault. Built with Tauri, React, and Rust; currently pre-1.0.

View GitHub repository ↗All projects ←
OVERVIEW

Keevra is a local-first Windows desktop application for organizing accounts across services. Accounts and optional details are stored in an encrypted vault file on the user's computer rather than being synced to a cloud account.

The app provides a searchable, service-grouped account directory with automatic saves, undo and redo, custom fields, and encrypted file attachments.

Keevra is currently pre-1.0. Its source code is publicly available under the MIT license, but no public installer has been released yet. Until a public release has been reviewed, the project recommends using test data only.

FEATURES

What it includes

  • Searchable accounts grouped by service, with tags and optional custom fields.
  • Local vault encryption using Argon2id key derivation and XChaCha20-Poly1305.
  • Automatic saving, undo/redo, and auto-lock after five minutes of inactivity.
  • Encrypted attachments and portable encrypted export/import packages.
  • Windows desktop app with light/dark themes and optional GitHub update checks.
